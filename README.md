Software Engineer at **[Viero](https://viero.me)** building fleet management and fintech systems. I design backends, manage cloud infrastructure, ship frontends, and somehow still have time to compete in global penetration testing competitions.

Based in **Amman, Jordan**. CS student at **Princess Sumaya University for Technology** (year 5. don't ask.) and Vice President of the Cybersecurity Club — which mostly means I get blamed when the CTF infrastructure goes down at 2 AM.

5+ years of building things that work, deploying things that stay up, and breaking into things I'm allowed to break into. If you need something built — I'll build it. If you need something broken — I'll break it. Either way, you should probably hire me.
